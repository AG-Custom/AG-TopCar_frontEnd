# Logos das marcas

Os arquivos PNG foram obtidos de [car-logos-dataset](https://github.com/filippofilip95/car-logos-dataset), que identifica [Carlogos.org](https://www.carlogos.org/) como origem das imagens. Effa e Shineray vieram dos sites oficiais das marcas. O SVG de Ora veio do Wikimedia Commons; o de Jaecoo, de [VehicleSpecs](https://github.com/vehiclespecs/brand-logos).

As marcas e seus logotipos pertencem aos respectivos titulares. O script `scripts/download-brand-logos.py` reproduz a preparação dos arquivos a partir do catálogo do backend.
